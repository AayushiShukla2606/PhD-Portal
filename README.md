## 📌 About the Project

Managing a PhD program involves mountains of paperwork, manual follow-ups, and coordination across departments. This portal replaces that chaos with a clean, centralized digital system.

Built for **Banasthali Vidyapith**, it automates the end-to-end PhD process — from initial registration to progress tracking — reducing paperwork and improving workflow efficiency for students, supervisors, and administrators alike.

---

## ✨ Features

- 📝 **Online Registration** — Students can register for the PhD program digitally
- 📁 **Document Submission** — Upload and manage required documents in one place
- 📊 **Progress Tracking** — Monitor PhD milestones and submission status
- 👥 **Role-based Access** — Separate views for students, supervisors, and admins
- 🔔 **Status Updates** — Real-time visibility into application and approval stages
- 📉 **Paperwork Reduction** — Eliminates manual, paper-based processes entirely

## 🚀 Getting Started

### Prerequisites
- Java JDK 8+
- Oracle Database
- Apache Tomcat (or any Java Servlet container)

### Setup

```bash
# Clone the repository
git clone https://github.com/AayushiShukla2606/PhD-portal.git

# Navigate to the project directory
cd PhD-portal
```

1. Import the Oracle DB schema from `/database/schema.sql`
2. Update DB credentials in `config/db.properties`
3. Deploy the `.war` file to your Tomcat server
4. Access the portal at `http://localhost:8080/phd-portal`
